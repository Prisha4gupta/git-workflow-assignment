Project Overview

This project is a practical demonstration of a Git and GitHub version control workflow. It was created as part of an academic assignment to reinforce understanding of core Git operations and collaborative development practices.

The repository tracks the full lifecycle of a small web project — from initial setup and feature development to history management and remote synchronization — using only industry-standard Git commands.

Git Workflow Demonstrated

The following Git workflow was followed in this assignment:

  • Repository Initialization: Created a local Git repository using git init -b main.
  • Staging & Committing: Used git add and git commit to record changes in stages.
  • Branching: Created a feature branch with git switch -c feature for isolated development.
  • Merging: Integrated the feature branch back into main using git merge feature.
  • Ignoring Files: Configured a .gitignore file to exclude log files and temporary directories.
  • Undo Operations: Used git revert HEAD to safely undo a commit while preserving history.
  • Remote Push: Connected the local repository to GitHub using git remote add origin and pushed both branches.

Features of the Git Workflow

  • Local Repository Initialization: The project begins by initializing a Git repository locally, establishing the project root and enabling version tracking from the first file.
  • Version Control: Every meaningful change is committed with a descriptive message, creating a permanent and traceable record of the project's evolution.
  • Branching: A dedicated feature branch was created to develop new functionality in isolation, keeping the main branch stable throughout.
  • Merging: After completing work on the feature branch, it was merged into main, integrating all changes into the primary codebase.
  • Commit History: A clean, linear commit history is maintained, making it straightforward to review what changed, when, and why.
  • GitHub Integration: The local repository was connected to a remote repository on GitHub, enabling backup, sharing, and collaboration through git push.
