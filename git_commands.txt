1. git init -b main
   Initializes a new Git repository in the current directory and sets the
   default branch name to 'main'. This creates the hidden .git folder that
   tracks all version history for the project.
   Usage: git init -b main

2. git config
   Sets configuration values for the Git repository. Used here to set the
   author name and email that appear in every commit record.
   Usage: git config user.name "Prisha Gupta"
          git config user.email "prishag407@gmail.com"

3. git status
   Displays the current state of the working directory and staging area.
   Shows which files are untracked, modified, or staged for commit.
   Usage: git status

4. git add
   Stages file changes so they are included in the next commit. Files can
   be added individually or all at once.
   Usage: git add index.html about.html
          git add index.html
          git add about.html
          git add .gitignore
          git add git_commands.txt

5. git commit
   Records the staged changes as a new commit in the repository history.
   The -m flag allows providing a commit message inline.
   Usage: git commit -m "Initial project structure"
          git commit -m "Update home page content"
          git commit -m "Add Git workflow features"
          git commit -m "Add gitignore rules"
          git commit -m "Add temporary announcement"
          git commit -m "Add git commands reference file"

6. git switch
   Switches between branches. The -c flag creates a new branch and switches
   to it in one step.
   Usage: git switch -c feature     (create and switch to feature branch)
          git switch main            (switch back to main branch)

7. git branch
   Lists all local branches in the repository. The active branch is marked
   with an asterisk (*).
   Usage: git branch
          git branch -a             (list all local and remote branches)

8. git merge
   Integrates changes from one branch into the current branch. Used to
   bring the feature branch changes into main after development is complete.
   Usage: git merge feature

9. git log
   Displays the commit history of the repository. Combined flags provide
   a visual graph, short hashes, branch labels, and all branch history.
   Usage: git log --oneline --graph --decorate --all

10. git revert
    Creates a new commit that undoes the changes introduced by a specified
    commit, without deleting the original commit from history. This is the
    safe way to undo changes on a shared or public branch.
    Usage: git revert HEAD --no-edit

11. git remote
    Manages connections to remote repositories. 'add' registers a new remote,
    while '-v' lists all configured remotes and their URLs.
    Usage: git remote add origin https://github.com/Prisha4gupta/git-workflow-assignment.git
           git remote -v

12. git push
    Uploads local branch commits to the remote repository on GitHub. The
    -u flag sets the upstream tracking reference so future pushes can be
    done with just 'git push'.
    Usage: git push -u origin main
           git push -u origin feature
           git push
