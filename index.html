Project Overview

This project demonstrates a complete Git and GitHub version control workflow, covering repository initialization, staged commits, branching, merging, .gitignore configuration, and undo operations using git revert.

The workflow follows professional development practices, ensuring a clean, traceable commit history from initial setup through feature integration.

Purpose of the Project

Version control is a cornerstone of modern software engineering. This project serves as a hands-on demonstration of how Git manages changes to source code over time, allowing developers to collaborate efficiently, roll back mistakes, and maintain a reliable project history.

Through this assignment, the following core Git concepts are exercised in practice: initializing a repository, staging and committing changes, creating and merging feature branches, ignoring unwanted files, and safely undoing commits without rewriting history.
